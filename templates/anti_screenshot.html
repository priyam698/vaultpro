Zero-Knowledge Ephemeral Canvas Stage

Visual Privacy Shielding.
Protected Against Capture.

The Zephyr Preview Stage employs multi-layered client safeguards. Files are rendered dynamically in isolated HTML5 Canvas viewports without saving unencrypted assets to the recipient's persistent browser cache.

👁️

Window Blur Obfuscation

The instant the browser window loses focus or screen recording shortcuts are invoked, the preview stage applies an aggressive gaussian blur filter and masks the viewport.

🔒

Right-Click & Context Locks

Default browser context actions—including "Save Image As", drag-to-desktop, and print menus—are intercepted and disabled on protected review stages.

⚡

RAM-Only Canvas Buffering

Media renders into ephemeral canvas raster buffers. The browser network cache stores only encrypted byte blocks, leaving no plaintext traces on local disk.

Dynamic Viewer Safeguards

For enterprise document reviews and media releases, Zephyr overlays recipient IP addresses, dynamic timestamps, and user-agent watermarks across confidential viewports. This discourages analog optical photography and unauthorized camera captures.
