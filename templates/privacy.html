Privacy Policy

Effective Date: September 2026

1. Zero-Knowledge Architecture

Zephyr operates on zero-knowledge encryption principles. Files stored in Zephyr Drive or transferred through our ephemeral pipelines are isolated at the edge. Plaintext passcodes and client encryption keys are never stored on our database servers, preventing internal staff or third parties from reading your file contents.

2. Zephyr Drive Storage Handling

When uploading files to Zephyr Drive:

  • Storage Isolation: Objects are stored within dedicated, user-isolated prefixes in Cloudflare R2 edge object storage.
  • Metadata Tracking: We track file size, MIME type, and creation date strictly for account quota enforcement (e.g., Free 5 GB / Pro 200 GB).
  • Permanent Retention: Drive objects remain stored indefinitely until you click "Delete" in your dashboard.
  • Instant Shredding: Deleting a Drive file triggers an immediate S3 purge call, permanently expunging the object from edge replicas.

3. Ephemeral Transfers & Burn-on-Read

Files sent via public transfer links are governed by automated expiration counters (1 to 72 hours) or Burn-on-Read limits. The moment a Burn-on-Read download completes or a link expires, the file is automatically purged with zero residual archival.

4. Third-Party Infrastructure Sub-processors

Zephyr uses vetted infrastructure providers:

  • Cloudflare R2: Edge object storage with zero egress fees and AES-256 server-side encryption.
  • Supabase: Encrypted PostgreSQL user authentication and database management.
  • Render: API compute execution and TLS edge termination.

5. Cookies & Analytics

Zephyr does not use tracking cookies, analytics pixels, or ad networks. LocalStorage is used strictly to retain user session tokens and the complimentary 4-upload guest counter.
