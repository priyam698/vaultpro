Frequently Asked Privacy & Security Questions

Can Privora or its cloud operators inspect my files? ▾

No. When you set a passcode, encryption is derived on your local browser. Privora stores encrypted blobs across Cloudflare R2 without keeping the decryption keys in our databases.

How does "Burn on Read" work? ▾

If you set "Max Downloads" to 1, the file is immediately expunged from edge storage the exact millisecond the recipient's download stream completes. Any subsequent access displays an expired vault error.

What file extensions are supported? ▾

All binary formats are accepted without restriction: video reels (MP4, MOV, ProRes), spreadsheets (XLSX, CSV), documents (PDF, DOCX), archives (ZIP, TAR, 7Z), and raw disk images.
