01

Zero-Knowledge Mathematical Model

Zephyr is built on an unconditional cryptographic premise: the host server must never possess the mathematical capacity to inspect client plaintext.

When an asset is dragged into Zephyr, a pseudo-random cryptographic key is generated inside the browser via window.crypto.getRandomValues(). The key is appended exclusively to the URL fragment identifier (following the # character). Under W3C and RFC 3986 specifications, URL hash fragments are strictly client-side and are never transmitted in HTTP request headers to any web server or network intermediary.

02

AES-256-GCM Galois/Counter Mode

Deliverables are encrypted chunk-by-chunk using the Advanced Encryption Standard with a 256-bit key in Galois/Counter Mode (AES-256-GCM).

Authenticated Encryption

GCM generates an authentication tag alongside ciphertext, mathematically preventing replay attacks or data tampering in transit.

Hardware Acceleration

Utilizes native AES-NI CPU instructions via the Web Crypto API, achieving multi-gigabyte throughput with negligible memory overhead.

03

Burn-on-Read Edge Shredding

Standard cloud drives retain residual file blocks for weeks even after deletion. Zephyr’s Burn-on-Read feature enforces atomic destruction.

The moment the recipient's browser stream receives the final byte of the download payload, the Cloudflare R2 worker issues an unauthenticated unmap command. Storage pointers are expunged and the encryption initialization vectors are discarded, rendering subsequent reconstruction impossible.

04

Anti-Screenshot Glare & Watermarking

For creative agencies previewing commercial video edits and brand designs before invoice settlement, client review stages must prevent screen capture theft.

Zephyr renders client review previews inside an obfuscated HTML5 Canvas element overlaying variable high-frequency luminance noise and dynamic diagonal watermarks displaying the client’s IP address, timestamp, and email identity. Automated OCR screen scrapers and recording software capture distorted frames.

05

Cloudflare R2 Direct Pipe Streaming

Unlike legacy services where gigabytes pass through bottlenecked centralized application servers, Zephyr leverages presigned S3-compatible multi-part chunk uploads.

Your browser streams encrypted binary chunks directly into Cloudflare R2 edge locations worldwide. This architecture guarantees zero middleman proxy latency, zero bandwidth throttling, and zero egress bandwidth taxes passed on to creators.
